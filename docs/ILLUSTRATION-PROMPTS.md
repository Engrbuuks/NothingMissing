# Illustration prompts

Five illustrations for the marketing site. Each prompt is self-contained and
paste-ready — one cell, no editing, no reference to the others.

**Save each result as PNG at the stated size into `public/illustrations/` using
the exact file name.** The slots already exist and are sized correctly; the
hatched placeholder disappears the moment the file lands.

---

## The style, and why

Isometric, flat vector, Nigerian context, transparent background. One
consistent palette across all five so the page reads as one set rather than
five stock images:

| | |
|---|---|
| Deep navy | `#061F3E` — structures, outlines, dark surfaces |
| Brand blue | `#0551BD` — primary shapes, vehicles, roofs |
| Light blue | `#085ED5` — highlights, secondary faces |
| Pale blue | `#E7EFFC` — ground planes, soft fills |
| Amber | `#F0A22E` — accents only: hard hats, cones, forklifts, highlights |
| White | `#FFFFFF` — knockouts and paper |

Amber is roughly **10% of the image**. It is an accent, not a second brand
colour — the brand is one blue and everything derives from it.

No gradients beyond a single flat shade step per face. No drop shadows except a
soft ground shadow. No text or numbers inside the artwork: the page supplies
those, and baked-in text cannot be translated or corrected.

## 1. `hero-depot-network` — 1200 × 900

```
Create a flat isometric vector illustration on a fully transparent background, 1200 x 900 pixels, no text or numbers anywhere in the image.

Scene: three connected industrial sites viewed from a raised isometric angle, arranged loosely across the frame. On the left, a warehouse depot with an open roller shutter and stacked pallets visible inside. In the centre and slightly forward, a small branch office building with a flat roof and glass frontage. On the right and slightly back, an open site yard with a diesel generator on a skid, a stack of drums, and a small forklift.

Connecting them: a raised road or path in pale blue that curves between all three sites, with one delivery truck travelling along it carrying a crate. Small floating route markers sit along the path — simple geometric pins, no text.

Include two or three Nigerian workers in the scene at small scale: one in a hard hat directing the forklift, one at the office entrance with a tablet, one beside the generator. Diverse skin tones, practical workwear.

Palette, used strictly: deep navy #061F3E for outlines and dark surfaces, brand blue #0551BD for the main structures and the truck body, lighter blue #085ED5 for roof faces and highlights, pale blue #E7EFFC for the ground plane and soft fills, amber #F0A22E for accents only — hard hats, the forklift, traffic cones, roughly 10% of the image. White #FFFFFF for knockouts.

Style: clean flat vector, isometric projection, uniform 2px outlines where outlines are used, one flat shade step per face, no gradients, no photorealism, no drop shadows except a single soft ground shadow beneath each structure. Generous negative space around the composition so it sits comfortably beside a block of text. Corporate, calm, competent — not playful, not cartoonish.
```

## After generating

1. Save each as PNG with a transparent background, at the stated pixel size.
2. Name them exactly as the headings above: `hero-depot-network.png` and so on.
3. Drop them into `public/illustrations/`.
4. Compress before committing — [squoosh.app](https://squoosh.app) at around
   80% quality typically takes a 1200px PNG from about 800 KB to 150 KB. These
   load on the first page a stranger ever sees, and a slow first impression is
   the one they keep.

If a result comes back with text baked in, or with more amber than blue, ask
for it again rather than accepting it — one image drifting from the set is more
noticeable than all five being slightly imperfect.
